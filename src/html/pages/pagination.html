Pagination

Пагінація у WordPress використовується для розділення великої кількості записів на декілька сторінок. Це дозволяє покращити навігацію по контенту та зменшити навантаження на сторінку, оскільки відображається лише певна кількість постів за один запит.

Найчастіше пагінація використовується на сторінках блогу, архівах категорій або у кастомних циклах WP_Query. WordPress автоматично визначає поточну сторінку через параметр paged, після чого відповідні записи отримуються з бази даних. Для виведення навігації між сторінками зазвичай використовується функція paginate_links(). 


<?php

$paged = (get_query_var('paged')) ? get_query_var('paged') : 1;

$args = [
    'post_type' => 'post',
    'posts_per_page' => 6,
    'paged' => $paged
];

$query = new WP_Query($args);

if ($query->have_posts()) :
    while ($query->have_posts()) : $query->the_post();
?>

<article class="post-card">
    <h2><?php the_title(); ?></h2>
    <a href="<?php the_permalink(); ?>">Read more</a>
</article>

<?php
    endwhile;
?>

<div class="pagination">
<?php
echo paginate_links([
    'total' => $query->max_num_pages
]);
?>
</div>

<?php
    wp_reset_postdata();
endif;

?>

Основна інформація

Під час роботи пагінації WordPress зберігає номер поточної сторінки у змінній paged. Цей параметр передається у WP_Query, щоб отримати правильну частину записів із бази даних. Якщо користувач переходить на другу або третю сторінку, WordPress автоматично змінює значення параметра paged і запит повертає інший набір постів.

💡 Без передачі параметра paged у WP_Query пагінація не буде працювати, оскільки кожна сторінка буде показувати однакові записи.

Вихідні параметри

Функція paginate_links() генерує список посилань для переходу між сторінками. Вона враховує загальну кількість сторінок, поточну сторінку та автоматично створює правильні URL для навігації. Зазвичай ця функція використовується після завершення циклу постів.

Parameter Description Example
total Total number of pages $query->max_num_pages
current Current page $paged
mid_size Number of pages around current 2
prev_text Previous page label Prev
next_text Next page label Next

Рекомендації

Пагінацію варто використовувати на сторінках, де відображається велика кількість записів. Це покращує читабельність сторінки та зменшує навантаження на сервер, оскільки одночасно завантажується менше контенту. Найчастіше вона застосовується у блогах, архівах категорій, новинних стрічках та кастомних списках постів.

Для більш складних проєктів пагінацію можна стилізувати або обгорнути у власний компонент. Це дозволяє використовувати однаковий дизайн навігації по всьому сайту та легко змінювати його у майбутньому.
