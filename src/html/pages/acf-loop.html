Flexible ACF цикл

Опис роботи:

Цей шаблон сторінки використовує поле Flexible Content з плагіна Advanced Custom Fields для побудови сторінки з незалежних компонентів. Кожен блок у редакторі відповідає окремому компоненту шаблону та може мати власні стилі.

Архітектура побудована так, щоб:

  • редактор міг складати сторінку з блоків у адмінці
  • кожен блок мав окремий PHP-шаблон
  • кожен блок мав окремий CSS файл
  • стилі не підключались повторно

<?php
/**
 * @package start theme
 */

/* Template Name: Front page */

get_header();
?>

<style>
<?php 
include get_stylesheet_directory() . '/css/pages/index.css'; 
?>

<?php
$loaded_styles = [];

if (have_rows('flexible_content')):
    while (have_rows('flexible_content')) : the_row();
    
        $layout = get_row_layout();
        
        if (!in_array($layout, $loaded_styles)) {
            $file = get_stylesheet_directory() . "/css/components/{$layout}.css";
            
            if (file_exists($file)) {
                include $file;
                $loaded_styles[] = $layout;
            }
        }
        
    endwhile;
endif;
?>
</style>

<?php
if (have_rows('flexible_content')):
    while (have_rows('flexible_content')) : the_row();
    
        $layout = get_row_layout();
        
        get_template_part("template-parts/components/{$layout}");
        
    endwhile;
endif;
?>

<?php
get_footer();
?>

Логіка роботи:

  • WordPress перевіряє, чи є блоки у полі flexible_content.
  • Для кожного блоку отримується його layout name через get_row_layout().
  • Назва layout використовується як назва CSS файлу компонента.
  • Якщо такий файл існує — він підключається.
  • Назва layout додається у масив $loaded_styles, щоб той самий CSS не підключився повторно, якщо блок використовується кілька разів.
