Виведення навігаційного меню

У WordPress навігаційне меню створюється в адміністративній панелі сайту у розділі Зовнішній вигляд → Меню. Після створення меню його можна прив’язати до певної локації меню, яка визначається у темі. Це дозволяє гнучко керувати структурою навігації без зміни коду.

Щоб меню можна було використовувати у темі, спочатку потрібно зареєструвати локацію меню. Після цього у шаблоні сторінки або в компоненті шапки сайту можна вивести меню за допомогою функції wp_nav_menu(). 


<?php

function register_theme_menus() {

    register_nav_menus([
        'main_menu' => 'Головне меню'
    ]);

}

add_action('after_setup_theme', 'register_theme_menus');

?>

Виведення меню у шаблоні

Після реєстрації локації меню його можна вивести у будь-якому шаблоні теми. Найчастіше меню виводиться у файлі header.php, щоб воно відображалось на всіх сторінках сайту.

Для цього використовується функція wp_nav_menu(), яка отримує параметри та генерує HTML структуру меню. 


<?php

wp_nav_menu([
    'theme_location' => 'main_menu',
    'container' => 'nav',
    'menu_class' => 'menu'
]);

?>

Принцип роботи

Після реєстрації локації меню WordPress дозволяє прив’язати до неї будь-яке меню, створене у адмін-панелі. Коли у шаблоні викликається функція wp_nav_menu(), система знаходить меню, яке прив’язане до відповідної локації, і автоматично генерує HTML список з пунктами меню.

💡 Якщо меню не прив’язане до локації, функція wp_nav_menu() може нічого не вивести або використати резервне меню зі сторінок сайту.

Рекомендації використання

Рекомендується створювати окремі локації меню для різних частин сайту, наприклад головне меню, меню у футері або мобільне меню. Це дозволяє керувати кожним меню незалежно та спрощує підтримку теми.

Для складніших проєктів меню часто виносять у окремий компонент, наприклад у файл template-parts/header/menu.php. Такий підхід робить структуру теми більш модульною і дозволяє повторно використовувати один і той самий код у різних місцях сайту.
