Шорткоди (Shortcodes)

Шорткоди у WordPress дозволяють вставляти динамічний контент у текст сторінки або запису за допомогою спеціального короткого синтаксису. Вони використовуються для виведення різних елементів сайту без написання HTML або PHP коду безпосередньо у редакторі.

Шорткод виглядає як невелика текстова конструкція у квадратних дужках, наприклад [example]. Коли WordPress обробляє сторінку, він знаходить цей запис і викликає функцію, яка генерує відповідний HTML або інший контент.

Шорткоди часто використовуються для вставлення кнопок, галерей, контактних форм або інших інтерактивних елементів прямо у текст сторінки. 


<?php

function example_shortcode() {

    return '<div class="example">Hello from shortcode</div>';

}

add_shortcode('example', 'example_shortcode');

?>

Принцип роботи

Шорткод створюється за допомогою функції add_shortcode(), яка приймає два параметри: назву шорткоду та функцію, що буде виконуватися при його виклику. Коли WordPress зустрічає відповідний запис у контенті сторінки, він викликає функцію і підставляє результат її роботи у HTML сторінки.

💡 Функція шорткоду повинна повертати результат через return, а не виводити його через echo.

Використання шорткоду

Після реєстрації шорткод можна використовувати у будь-якому текстовому полі WordPress: у записах, сторінках або віджетах. Для цього достатньо вставити його назву у квадратних дужках. 


[example]

Рекомендації використання

Шорткоди зручно використовувати для елементів, які потрібно вставляти у контент багато разів. Це дозволяє централізовано керувати їхньою логікою у коді теми або плагіна.

У складніших проєктах шорткоди часто використовуються разом із ACF або іншими даними з бази, щоб створювати гнучкі блоки контенту, які редактор може вставляти у будь-яке місце сторінки.
