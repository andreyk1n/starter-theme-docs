Кастомні типи записів (Custom Post Types)

Кастомні типи записів у WordPress дозволяють створювати власні типи контенту, які відокремлені від стандартних записів та сторінок. Це зручно у випадках, коли сайт має декілька різних типів інформації, наприклад новини, проєкти, портфоліо, відгуки або товари.

Такий підхід допомагає структурувати контент та спрощує керування сайтом у адмін-панелі. Кожен тип записів має власний розділ у меню адміністратора, власні шаблони сторінок та може мати окремі таксономії, поля ACF або архівні сторінки.

Кастомний тип записів створюється за допомогою функції register_post_type(), яка викликається під час ініціалізації WordPress. У параметрах функції визначається назва типу записів, мітки для адмін-панелі, підтримувані можливості та інші налаштування. 


<?php

function register_projects_post_type() {

    register_post_type('projects', [
        'labels' => [
            'name' => 'Проєкти',
            'singular_name' => 'Проєкт',
            'add_new' => 'Додати проєкт',
            'add_new_item' => 'Додати новий проєкт'
        ],
        'public' => true,
        'has_archive' => true,
        'menu_icon' => 'dashicons-portfolio',
        'supports' => [
            'title',
            'editor',
            'thumbnail'
        ],
        'rewrite' => [
            'slug' => 'projects'
        ]
    ]);

}

add_action('init', 'register_projects_post_type');

?>

Принцип роботи

Після реєстрації кастомного типу записів WordPress автоматично створює новий розділ у адміністративній панелі. У цьому розділі можна додавати, редагувати та видаляти записи так само, як і звичайні пости. Кожен запис може містити заголовок, текст, зображення та інші поля, які визначаються через параметр supports.

Якщо у параметрах вказано has_archive, WordPress створює архівну сторінку для цього типу записів. Вона буде доступна за адресою, яка визначається параметром slug.

💡 Найчастіше кастомні типи записів використовуються разом із ACF, щоб додавати до записів додаткові поля та створювати більш складні структури контенту.

Шаблони для кастомних записів

WordPress автоматично використовує template hierarchy для відображення сторінок кастомних записів. Це означає, що для кожного типу записів можна створити власні шаблони сторінок.

Шаблон Призначення
archive-projects.php Архів усіх записів типу projects
single-projects.php Сторінка одного запису

Рекомендації використання

Кастомні типи записів варто використовувати у випадках, коли на сайті з'являється новий тип контенту, який логічно відокремити від стандартних постів або сторінок. Це дозволяє створити більш зрозумілу структуру сайту та спростити роботу редакторів з адміністративною панеллю.

Для складніших проєктів рекомендується поєднувати кастомні типи записів із ACF та кастомними таксономіями. Такий підхід дозволяє створювати гнучкі структури контенту, які легко масштабуються та підтримуються у майбутньому.
